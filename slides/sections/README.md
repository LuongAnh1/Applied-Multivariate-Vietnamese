# Chia phần slide

Thư mục này chỉ chia khúc nội dung theo mục gốc của Chapter 5, chưa gắn tên thành viên phụ trách. Trên PDF, Beamer sẽ tự đánh số 1, 2, 3... nên tiêu đề trong các file không ghi lại 5.1, 5.2.

| File | Phạm vi gốc | Tiêu đề hiển thị |
| --- | --- | --- |
| `section_5_1_introduction.tex` | Mục 5.1 | Giới thiệu |
| `section_5_2_plausibility_mu0.tex` | Mục 5.2 | Tính hợp lý của `\\mu_0` |
| `section_5_3_hotelling_likelihood.tex` | Mục 5.3 | Hotelling `T^2` và kiểm định tỷ số hợp lý |
| `section_5_4_confidence_regions.tex` | Mục 5.4 | Miền tin cậy và so sánh đồng thời |
| `section_5_5_large_sample.tex` | Mục 5.5 | Suy luận mẫu lớn |
| `section_5_6_quality_control.tex` | Mục 5.6 | Kiểm soát chất lượng đa biến |
| `section_exercises.tex` | Bài tập | Bài tập và ví dụ tính toán |

Khi nhận phần nào, chỉ sửa file tương ứng. File `../main.tex` chỉ dùng để cấu hình chung, tiêu đề, thứ tự các mục và trang mở/kết.
